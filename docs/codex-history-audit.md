## 主要结论

历史对话反复确认了三个边界：

1. 概率是模型输出，不是下注建议。
2. 输入需要审计，尤其是来源版本和强度版本。
3. 赛后修正只能进入下一版快照，不能改写已发布预测。

## 对新项目的转化

- 用 `SKILL.md` 固化 agent 行为边界。
- 用 `scripts/` 固化可重复命令。
- 用 `references/` 固化解释和审计规则。
- 用 `examples/` 提供国内用户能看懂的样例。
- 用 `docs/` 说明模型来源、历史审计和开源使用方法。
