# 流程图定稿说明

本项目的流程图最终采用 image2 重新生成，不再使用 SVG 或本地脚本生成流程图。整体风格采用红白中文工程信息图：米白纸感背景、深红主色、黑色粗标题、圆角白色信息块、红色编号徽章、细线图标和闭环箭头。

## 设计目标

这些图不是给技术人员炫公式，而是让第一次看到项目的人快速理解三件事：

1. 模型不是“AI 直接猜比分”，而是资料进入快照后再计算。
2. 胜率来自可审计的数据、预期进球、比分矩阵和胜平负汇总。
3. 赛后修正不是修改旧答案，而是把新事实写进下一版快照。

## 视觉规范

- 主色：深红、黑色、米白。
- 版式：竖版信息图，适合 GitHub README、项目简介和文档预览。
- 语言：全部使用简体中文，保留 `Skill` 只用于项目名语境。
- 风险表达：底部保留“概率 ≠ 结果”或“旧预测不修改”的提醒。
- 禁止元素：下注、竞猜、收益、盘口、赌博暗示、平台水印。

## 后续迭代规则

如果后续需要重画流程图，应优先保持这套 red-white workflow 风格。文字可以随着模型能力更新，但流程边界不能变：

- 新事实必须进入快照。
- 快照必须经过审计。
- 概率必须由模型重新计算。
- 旧预测只能复盘，不能回头修改。
