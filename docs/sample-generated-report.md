## 这组概率从哪里来

1. 先把球队身价/评分、FIFA 排名或 Elo、近期状态、进攻强度、防守强度放进同一个输入快照。
2. 审计脚本检查版本号、来源、球队数量、强度版本和修正来源，避免不同批次数据混用。
3. 模型把双方强弱差、状态差、攻防系数和赛地因素换算为预期进球。
4. 预期进球进入泊松比分矩阵，并用 Dixon-Coles 对低比分相关性做轻量修正。
5. 最后把所有主胜、平局、客胜比分格子分别相加，得到 90 分钟胜平负概率。
