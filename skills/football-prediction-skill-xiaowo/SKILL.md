# 小蜗通用足球预测

使用通用赛事边界建立可审计的足球预测流程。该 Skill 是独立的 v3 入口，不覆盖既有的世界杯预测 Skill 或 `worldcup-xiaowo` 命令。

## 工作流程

1. 确认比赛属于支持的赛事类别：联赛、国内杯赛、洲际俱乐部赛事、国家队赛事或友谊赛。
2. 保留赛程、球队状态和其他预测输入的来源与时间信息，避免把未经核验的内容直接写入结论。
3. 将 90 分钟概率、比分候选和不确定性说明与输入证据对应；不要把预测表述为确定结果。
4. 赛后记录实际结果与偏差，为下一次预测提供可复核的修正依据。

## 兼容边界

保持该目录的核心模块与 v1 模块相互独立。需要世界杯专用流程时，继续使用 `worldcup-prediction-skill-xiaowo` 和 `worldcup-xiaowo`。
